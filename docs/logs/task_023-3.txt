=== task_023 supportedModes 実測（AppIntents メタデータ抽出）===
同じ AlarmSpike ターゲットを 4 通りビルドし、
build/Debug-iphonesimulator/AlarmSpike.app/Metadata.appintents/extract.actionsdata の
actions.OpenSaydoIntent を読んだ結果。ビルドは 4 通りとも exit 0（警告なし）。

| OpenSaydoIntent の宣言 | supportedModes | openAppWhenRun |
|---|---|---|
| static let supportedModes: IntentModes = .foreground(.immediate) | 1 | false |
| static let supportedModes: IntentModes = .background | 1 | false |
| static let openAppWhenRun = true（supportedModes を書かない） | 2 | true |
| static let supportedModes: IntentModes = .foreground | 2 | true |

結論: static func 形式の .foreground(.immediate) は定数畳み込みされず、
.background と同じ 1 が書き出される。static var 形式の .foreground は 2 になる。
コンパイラは両方を通すため、書き間違えても警告は出ない。最終形は .foreground を採用した。

openAppWhenRun = true
supportedModes = 2
