# 実機検証チェックリスト（2026-09-04、iPhone 16 Pro Max / iOS 26.6）

インストールは `SAYDO_TEAM_ID=… scripts/build-device.sh`。結果はこの表に書き、`docs/PROGRESS.md` の integration-2「人間の確認待ち」を更新する。
「責める文言が出た」「タップが余計に要った」は不具合として扱う。

## A. 初回起動（オンボーディング）

| # | 手順 | 期待 | 結果 |
|---|---|---|---|
| A1 | アプリを開く | オンボーディングが 1 回だけ出る。コンセプト 1 文 → マイク → 通知 → 時刻 → 一人で話せる時間 → 音声モデル → バックアップ注意 | |
| A2 | マイクと通知を許可 | ダイアログは各 1 回。拒否しても先へ進める | |
| A3 | 完了後 | 「今日」タブに「今話す」が出る。以後オンボーディングは出ない | |

## B. 朝フロー（3 回。画面録画を残す）

| # | 手順 | 期待 | 結果（1 / 2 / 3 回目） |
|---|---|---|---|
| B1 | 「今話す」をタップ | 1.5 秒以内に「おはよう。今日、いちばん逃げたいことは何？」が読み上げられる。波形が動く | |
| B2 | 声で答える（例: 見積書を送るのが嫌だ） | 文字起こしが 1 行出て、次の質問へ。タップ 0 回 | |
| B3 | M1 の理由 | チップ 7 個が 1 画面に収まる。声でもチップでも進む | |
| B4 | M2 / M3 | 「最初の 5 分でできる、いちばん小さいことは？」「何時に、どこで？」を声で答えると行動文と時刻・場所が決まる | |
| B5 | M4 の宣言 | 30 秒以内に録音され「受け取りました。◯時に、朝のあなたから届きます。」 | |
| B6 | 完走時間 | 3 回の中央値が 3 分以内（SessionLog は設定 → 開発者向け節で確認） | |
| B7 | 「今日」タブ | 宣言カードに行動文・時刻・場所・再生ボタン。再生で自分の声が鳴る | |

## C. 通知と昼フロー

| # | 手順 | 期待 | 結果 |
|---|---|---|---|
| C1 | 行動時刻を 2〜3 分後にして宣言 → アプリを閉じて待つ | 行動時刻通知が届く（集中モード ON でも届けば Time Sensitive が有効） | |
| C2 | 通知をタップ | Today を経由せず会話画面が出て「朝のあなたからです。」→ 宣言音声の再生 → 「どうだった？」 | |
| C3 | イヤホン無し・音量を上げて C2 | 音が出る前に「イヤホンで聞く / 文字で読む」が出る。「文字で読む」でも会話が進む | |
| C4 | 「少しやった」 | 「それを今日の前進として残すね。」で終了（N2 に進まない） | |
| C5 | 「まだ」→ 止めているものを声で → 言い直す | 行動文が置き換わる。「今日は捨てる」「明日に回す」も選べる | |
| C6 | 通知を長押し | 「今は話せない」「今日は休む」の 2 つ。「今は話せない」で 60 分後に同じ通知が 1 件 | |
| C7 | 「今日は休む」 | その日の残りの通知が消え、記録タブに何も増えない | |

## D. 夜フローと翌朝

| # | 手順 | 期待 | 結果 |
|---|---|---|---|
| D1 | 夜の時刻を数分後にして通知から開く（または「今話す」） | 「今日、少しでも前に進めたことは？」→「明日はどうする？」 | |
| D2 | 前進なしと答える | 「今日はそういう日。明日、もっと小さくしよう。」+ チップ 2 つだけ | |
| D3 | 翌朝（端末の日付を進めてもよい） | M0 が「昨日の夜『◯◯』って言ってたね。今日はそれでいく？」から始まる | |
