## タイポグラフィ（1ファミリーのみ）

`-apple-system, "Hiragino Sans", "Hiragino Kaku Gothic ProN", "BIZ UDPGothic", system-ui`。和欧で書体を分けず、weight・size・字間・行間だけで階層を作る。全和文に `font-feature-settings:"palt" 1` と `line-break:strict`。

size / weight / letter-spacing / line-height:
質問 **28 / 500 / .02em / 1.5** ／ 前置き（N0）22 / 400 / .06em ／ 画面タイトル 20 / 500 / .04em ／ 宣言本文 17 / 400 / **1.9** ／ 振り返り1文 16 / 400 / **2.0** ／ リスト・チップ 15–16 / 400 / 1.75 ／ 状態行 14 / 400 / **.20em** ／ 時刻・日付 12–13 + `tabular-nums` ／ セクションラベル 11 / 500 / **.24em** ／ ロゴ SAYDO 11 / 500 / **.38em** / `#6B7EA6`。

## 波形（SwiftUI Canvas 再現用）

`y(x) = cy − env(u)·A·norm·Σ aᵢ·sin(2π·fᵢ·u + φᵢ + t·ωᵢ)`、`u = x/W`、`norm = 1/Σaᵢ`。`ω` は位相ドリフト rad/s。Reduce Motion では `t` を止める（計画書 §8 は振幅バーへの切替を指定）。

**聞いている状態（M0 / M1）** 1本の生きた線。均一なバー羅列にしない。
`env(u) = exp(−((u−0.5)/0.30)²)`（M1 は σ=0.32）／成分 `(a, f, φ, ω)` = `(1.00, 2.6, 0.00, +0.55)` `(0.42, 5.7, 1.90, −0.90)` `(0.18, 11.3, 3.40, +1.60)`。
M0: W=320 cy=66 **A=40**／M1: W=280 cy=32 **A=20**（φ を `2.2 / 4.6 / 0.8` にずらす）。
4層描画: bloom 19px @.09（呼吸アニメ 3.6s）→ 8px @.24 → 反転線 A=−20 を 1.4px @.20 → 芯 **3px @1.0**。すべて `lineCap/lineJoin: .round`。

**再生波形（N0）** 上下対称のリボン（A と −A の2本）で「録音済み」を表す。
`env(u) = min(1, 0.55·g(u,.18,.10) + 1.00·g(u,.46,.13) + 0.72·g(u,.78,.11))`、`g` はガウス。3つの山＝3つの語句。
成分 `(1.00, 7.0, 0.6)` `(0.55, 15.0, 2.7)` `(0.25, 27.0, 5.1)`／W=340 cy=75 **A=40**／サンプリング 1px。
再生済み `x < 0.58W` は `#EDA96F`（bloom 9px @.11 → 4.5px @.15 → 芯 2.5px）、未再生は `#6E7FA6` 2px @.34。再生位置に 1.6px の縦線 `#F6C79E` @.65。進捗バーは置かない。

**線の色** 横方向 linearGradient: `#6E7FA6@.10` → 18% `#9A8B9B@.44` → 38% `#D6975F@.88` → 50% `#EDA96F@1.0` → 対称。中央だけが温かく、端は地に溶ける。
**質感** 140px タイルの `feTurbulence`（baseFrequency .86 / 3 octaves）を `opacity .045`・`mix-blend-mode: overlay` で全面に。会話3画面のみビネット（内側42%は透明、端で `rgba(8,13,24,.62)`）を背景と内容の間に敷く。

## 画面別コンポーネント

1. **SessionView 朝 M0** `Main.dc.html` — ロゴ／質問「今日、何から逃げたい？」／大波形 320×132／状態行「聞いています…」（opacity .5↔1.0 を 2.8s で呼吸）／右下 44×44 キーボード補助。チップ無し・触る要素1。
2. **SessionView 朝 M1** `SessionReason.dc.html` — 質問「一番近いのはどれ？」／小波形 280×64／状態行／理由チップ7種を **3 / 3 / 1** の意図的なラグで配置（高さ46・角丸15・`rgba(255,255,255,.045)`）／キーボード補助。
3. **PlaybackCard 昼 N0** `Playback.dc.html` — 「朝のあなたからです。」（アクセント色）／再生リボン 340×150／下部に「イヤホンで聞く｜文字で読む」（塗り無し・高さ46・ヘアライン区切り）。文字起こしは出さない（声を聴かせるため）。
4. **TodayView** `Today.dc.html` — ロゴ＋日付／「今日の約束」／宣言カード（本文・行動時刻 `14:00`・48px 再生）／余白／「今話す」64px ピル（親指の届く下部・波形グリフ付き）／2項目ナビ。
5. **TimelineView** `Timeline.dc.html` — 3件目インサイト1行（26px の温色ルール＋シェブロン、タップで週次へ）／日付セクション／各エントリは **SVG マイク＋時刻＋文字起こし1〜2行＋32px 再生**／マイクを結ぶ縦レール（`rgba(237,169,111,.22)`、マイク背後を `#101A2E` の円で断つ）。9月3日は記録が無いので**描かない**。
6. **WeeklyInsightView** `WeeklyInsight.dc.html` — 戻る／「この1週間」＋日付範囲／上位5（01が17px・以降16px の緩い減衰、件数は出さない）／「逃げる理由」の帯（高さ12・実幅 128/91/70/47px・隙間2px）＋凡例4行／振り返り1文（温色パネル、左ボーダー無し）。円グラフ・達成率は不使用。

## 前提と省略（実装前に確認）

- 🎙️ は絵文字ではなく**ストローク SVG のマイク**で描いた（暗色 UI で絵文字は浮くため。企画書の表記は記号の意図と解釈）。
- N0 の「イヤホンで聞く／文字で読む」は計画書 §7.2 R8 では**再生前**に出る。ブリーフの指定に従い再生中の状態で描いてある。
- 設定ギア（計画書 §8「今日」右上）はブリーフの「触る要素は各画面1〜3個」に従い作図から外した。タブバーは文字だけの最小表現。
- iOS のステータスバー・ホームインジケータ・仮想キーボードは意図的に描いていない（実機で二重になる）。上部 54–64px は安全領域として空けてある。
- 文言・時刻・件数は企画書 §10 §11 と計画書 §7.2 の実例。数値は分析ロジック確定後に差し替えること。
